# 涂家赫
幫我利用javascript加入新增待辦事項的機制，並特別加入一個每日事務，使用schedule的機制讓他在每天12pm自動將已打勾的事務設為還未完成的狀態

新增功能
新增待辦事項機制：
點擊 "Add" 按鈕可以從輸入框添加新任務
任務會動態添加到列表中

任務管理：
點擊checkbox可以標記任務為完成/未完成
點擊 "X" 按鈕可以刪除任務
任務狀態會自動保存到瀏覽器的localStorage中，頁面刷新後不會丟失

每日事務：
自動添加一個特殊的每日任務："每日事務：檢查所有任務"
這個任務不會被刪除（標記為daily）

自動重置機制：
每分鐘檢查一次當前時間
當到達中午12:00時，自動將所有已完成的任務（包括每日事務）重置為未完成狀態
重置後會重新保存並重新渲染列表

將那條每日任務刪除，並單獨在待辦事務區塊的上方獨立出一個區塊專門放每日固定要做的事情

主要更改
刪除原來的每日任務：

移除了JavaScript中自動添加"每日事務：檢查所有任務"的邏輯
新增獨立的每日固定任務區塊：

在待辦事務區塊上方添加了一個新的 <div class="daily-tasks-section">
包含標題"每日固定任務"
功能調整：
每日固定任務也有checkbox，可以標記完成/未完成
狀態會保存到localStorage中
重要：每日固定任務不會被12pm的自動重置機制影響，只有普通待辦任務會被重置
JavaScript更新：

分離了普通任務和每日任務的處理邏輯
每日任務使用單獨的localStorage key (dailyTasks)
重置機制只適用於普通任務

每日任務那邊也要加入一個可以新增刪除的機制

新增功能
每日任務的輸入框和按鈕：

在"每日固定任務"標題下方添加了輸入框
點擊 "Add" 按鈕可以添加新的每日固定任務
刪除功能：

每個每日任務旁邊都有 "X" 按鈕，可以刪除該任務
動態渲染：

每日任務現在完全由JavaScript動態生成（類似普通待辦任務）
所有更改都會自動保存到localStorage中
頁面刷新後數據不會丟失
現有功能保留
